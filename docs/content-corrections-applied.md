# Content PR (`pr/content`): what it applies

- **Branch:** `pr/content`, one commit on top of `pr/technical` (which is based on `main` 728e8f5). This document lives in the technical PR so that the content PR's diff is pin data only.
- **Why it is based on the technical branch (dependency):** 9 of the 23 edited pins (001–006, 008–010) change `timeline` and/or `sources`. `main` does not render those fields at all; they appear only through the technical branch's detail Timeline/Sources sections (and the `/pins/<slug>/` pages). The patch also applies cleanly to `main` (TESTED with `git apply --check`), but there the timeline/source corrections would be invisible.
- **Diff rule (automated):** `node scripts/content-diff-check.js pr/technical pr/content` must pass: only `index.html` changes, nothing outside the `LOCATIONS` array changes, same 99 pins/ids/order/slugs, only content fields change, and **no source reference is removed** (3 citations are corrected in place — same work, wrong title or a link that did not reach the document — and 1 source is added).
- The edits were generated by a local helper script (not committed) from `docs/content-corrections.md`.
- **Status:** NOT merged and NOT deployed. The owner reviews each item against `docs/content-corrections.md`.
